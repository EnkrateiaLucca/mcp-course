A tighter version of the paragraph

  

    
The MCP protocol is stateless as of spec 2026-07-28. The spec removed the initialize handshake and the Mcp-Session-Id header, so each client request is a self-contained POST that carries its protocol version and capabilities in _meta. Any replica can answer any request. You host the server like a web API: serverless, autoscaled, behind a plain round-robin load balancer. Application state that must survive between calls goes in a store you own, referenced by explicit handles.
